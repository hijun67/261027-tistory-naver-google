# 로컬 실행 방법 (Netlify 없이 내 컴퓨터에서)

## 1. 준비 (한 번만)
- **Node.js 18 이상** 설치 → https://nodejs.org (LTS 버전). 설치 확인: 터미널에서 `node -v`
- 별도의 `npm install` 은 **필요 없습니다.** (서버는 외부 패키지 없이 동작)
- **인터넷 연결 필요**: 변환 엔진(Pyodide)과 구글 로그인 스크립트를 CDN에서 불러오고, 티스토리/네이버 글을 읽어야 하기 때문입니다.

> 서버를 켠 뒤 **http://localhost:8080/local.html** 을 열면 사용법과 상태 점검(프록시·인터넷·구글 설정)을 한 화면에서 볼 수 있습니다.

## 2. 실행
| 환경 | 방법 |
|---|---|
| Windows | `start-local.bat` 더블클릭 |
| Mac / Linux | 터미널에서 `./start-local.sh` |
| 공통 | 터미널에서 `npm start` 후 브라우저에서 http://localhost:8080 접속 |

종료는 서버 창에서 `Ctrl + C`.

## 3. 구글(블로거) 로그인 설정 — 한 번만
구글 OAuth 는 접속 주소를 미리 등록해야 합니다.
1. https://console.cloud.google.com → API 및 서비스 → 사용자 인증 정보 → 사용 중인 **OAuth 클라이언트 ID(웹 애플리케이션)** 열기
2. **승인된 JavaScript 원본**에 `http://localhost:8080` 추가 → 저장 (반영까지 몇 분 걸릴 수 있음)
3. 클라이언트 ID 는 `public/config.js` 의 `clientId` 에 넣어 두었거나, 화면의 입력칸에 직접 입력합니다.
4. 앱이 "테스트" 상태이면 **OAuth 동의 화면 → 테스트 사용자**에 본인 구글 계정을 추가해야 로그인됩니다.
5. Blogger API 가 사용 설정되어 있어야 합니다.

> `127.0.0.1` 로 접속하면 구글이 다른 주소로 인식해 로그인이 실패합니다. 반드시 **localhost** 로 접속하세요.

## 4. 옵션
| 방법 | 설명 |
|---|---|
| `PORT=8081 npm start` (Windows: `set PORT=8081&& npm start`) | 포트 변경. 변경하면 구글 원본 목록에도 같은 주소를 추가해야 함 |
| `npm run start:dist` | `npm install && npm run build` 로 만든 난독화본(`dist/`)을 실행 |
| `HOST=0.0.0.0 npm start` | 같은 공유기의 다른 기기에서도 접속 허용 (기본은 내 컴퓨터만) |
| `node server.js --ads` | 화면 광고 스크립트도 로드 (기본은 로컬에서 제거) |

## 5. 동작 방식
- `server.js` 가 `public/` 폴더를 웹으로 제공하고, 티스토리/네이버 읽기 프록시(`netlify/functions/*.js`)를 **같은 코드 그대로** 로컬에서 실행합니다. 허용 도메인 검사(티스토리·네이버 글 주소만 중계)와 같은 출처 확인도 동일하게 적용됩니다.
- 로컬에서는 호출 횟수 제한을 사실상 해제했습니다. (Netlify 에서는 기존 제한 유지)
- `netlify/` 폴더는 로컬 실행에도 프록시 코드로 쓰이므로 **삭제하지 마세요.** (`netlify.toml` 은 Netlify 배포용이라 로컬만 쓸 거면 지워도 됩니다.)

## 6. 문제 해결
- **포트 사용 중**: 다른 번호로 실행 (위 옵션 참고)
- **글 목록이 안 읽힘 / 502**: 인터넷 연결 확인, 비공개 글이나 존재하지 않는 주소인지 확인
- **로그인 팝업에서 `origin_mismatch` 오류**: 3번의 승인된 JavaScript 원본이 `http://localhost:8080` 과 정확히 같은지 확인
- **수정한 코드가 안 바뀜**: 브라우저 강력 새로고침(Ctrl+F5). 서버는 캐시를 쓰지 않습니다.

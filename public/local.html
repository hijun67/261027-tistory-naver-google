프로그램 열기

로컬 사용 안내

내 컴퓨터에서 티스토리·네이버 블로그를 구글 블로거로 옮기는 방법입니다. 이 페이지가 보인다면 서버 실행은 이미 성공한 것입니다. 아래 점검 결과에서 빨간색이나 노란색이 있는 항목만 안내대로 고치면 됩니다.

지금 상태 점검
로컬 서버확인 중
접속 주소확인 중
글 읽기 프록시 (티스토리)확인 중
변환 엔진(Pyodide) 다운로드확인 중
구글 로그인 스크립트확인 중
구글 클라이언트 ID확인 중

처음 한 번 하는 준비

  1. Node.js 설치

    nodejs.org에서 LTS 버전을 설치합니다. 18 이상이면 됩니다. 이 프로그램은 별도의 npm install 없이 바로 실행됩니다.

  2. 구글 클라우드에 접속 주소 등록

    구글은 로그인 화면을 열 수 있는 주소를 미리 등록해 둔 곳에서만 허용합니다. 사용 중인 OAuth 클라이언트(웹 애플리케이션)의 승인된 JavaScript 원본에 아래 주소를 추가하고 저장합니다.

    등록할 주소
    http://localhost:8080

    경로는 쓰지 않고 주소만 입력합니다. 저장 후 반영까지 몇 분 걸릴 수 있습니다.

    등록 위치: 구글 클라우드 콘솔 → API 및 서비스 → 사용자 인증 정보

    127.0.0.1로 접속하지 마세요. 구글은 localhost와 127.0.0.1을 서로 다른 주소로 취급합니다. 반드시 localhost로 접속해야 합니다.

  3. 구글 계정과 API 설정 확인

    OAuth 동의 화면이 "테스트" 상태라면 테스트 사용자에 본인 구글 계정을 추가해야 로그인할 수 있습니다. 같은 프로젝트에서 Blogger API도 사용 설정이 되어 있어야 합니다.

  4. 클라이언트 ID 입력

    public/config.js의 clientId에 넣어 두면 화면에서 입력할 필요가 없습니다. 비워 두었다면 프로그램 화면의 입력칸에 직접 붙여 넣어도 됩니다. 위 점검 결과의 "구글 클라이언트 ID" 항목이 현재 상태를 알려 줍니다.

끌 때는 서버가 떠 있는 창에서 Ctrl + C를 누르거나 창을 닫습니다. 서버를 끄면 이 페이지와 프로그램도 열리지 않습니다.

이전하는 순서

  1. 프로그램 화면에서 구글 로그인

    블로거 블로그를 선택합니다. 이전할 글이 올라갈 대상 블로그입니다.

  2. 원본 블로그 주소 입력 후 글 목록 불러오기

    티스토리는 https://이름.tistory.com, 네이버는 블로그 주소나 아이디를 넣습니다. 비공개 글은 읽을 수 없습니다.

  3. 옮길 글 선택, 옵션 확인

    원본 작성일로 발행할지, 초안으로 저장할지, 목차나 소제목 변환을 쓸지 정합니다. 처음에는 글 한두 개만 골라 결과를 확인하고, 괜찮으면 나머지를 옮기는 것이 안전합니다.

  4. 이전 시작

    글 사이에 설정한 간격만큼 쉬면서 하나씩 올라갑니다. 진행 중에는 창을 닫지 마세요. 끝나면 블로거 관리 화면에서 결과를 확인합니다.

    이미 이전한 글을 다시 이전하면 같은 글이 블로거에 중복으로 생깁니다. 다시 해야 한다면 블로거에서 기존 글을 먼저 지우세요.

문제가 생겼을 때

구글 로그인 창에서 "origin_mismatch" 또는 "invalid_request" 오류가 나요

구글에 등록한 주소와 지금 접속한 주소가 한 글자라도 다르면 나는 오류입니다. 주소창의 주소가 위 "접속 주소" 항목과 같은지, 그 주소가 승인된 JavaScript 원본에 그대로 등록되어 있는지 확인하세요. 끝에 /를 붙이거나 https로 쓰면 다른 주소입니다. 방금 등록했다면 몇 분 기다린 뒤 다시 시도하세요.

로그인은 되는데 "access_denied" 또는 "확인되지 않은 앱"이 떠요

OAuth 동의 화면이 "테스트" 상태이면 테스트 사용자로 등록된 계정만 로그인할 수 있습니다. 본인 계정을 추가하세요. "확인되지 않은 앱" 경고는 본인이 만든 앱이면 고급 → 이동으로 계속 진행할 수 있습니다.

블로거에 글이 올라가지 않고 권한·API 오류가 나요

같은 구글 클라우드 프로젝트에서 Blogger API가 사용 설정되어 있는지 확인하세요. 로그인한 구글 계정이 선택한 블로그의 작성 권한을 갖고 있어야 합니다.

글 목록이 안 불러와져요 (502, 504, "upstream error")

내 컴퓨터가 인터넷에 연결되어 있고 티스토리·네이버에 접속되는지 확인하세요. 점검 결과의 "글 읽기 프록시"가 빨간색이면 서버가 외부 사이트에 접근하지 못하는 상태입니다. 회사·학교 네트워크, VPN, 방화벽이 원인인 경우가 많습니다. 블로그 주소 오타나 비공개 블로그인 경우에도 목록이 비어 나옵니다.

화면은 열리는데 변환이 시작되지 않고 "엔진 로딩"에서 멈춰요

변환 엔진(Pyodide)은 처음 실행할 때 인터넷에서 내려받습니다. 용량이 커서 첫 실행에는 시간이 걸립니다. 점검 결과의 "변환 엔진 다운로드"가 빨간색이면 cdn.jsdelivr.net에 접속하지 못하는 상태입니다. 네트워크나 광고 차단 프로그램 설정을 확인하세요.

"포트를 이미 다른 프로그램이 쓰고 있습니다"라고 나와요

이미 서버가 켜져 있거나 다른 프로그램이 8080번 포트를 쓰는 중입니다. 켜져 있는 서버 창이 있으면 그 창을 쓰거나 끄고, 아니면 위 옵션 표대로 다른 포트로 실행하세요. 포트를 바꾸면 구글 등록 주소도 함께 바꿔야 합니다.

코드를 고쳤는데 화면에 반영되지 않아요

서버는 캐시를 쓰지 않으므로 브라우저 강력 새로고침(Ctrl + F5, Mac은 ⌘ + Shift + R)이면 반영됩니다. start:dist로 실행 중이라면 npm run build를 다시 해야 합니다.

이 페이지는 내 컴퓨터에서만 보이는 안내문입니다. 서버를 켠 상태에서 /local.html 또는 /local 주소로 언제든 다시 열 수 있습니다.
